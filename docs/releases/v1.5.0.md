# Social Safe Area 1.5.0

- Dedicated first-run wizard with simple instructions before opening Android
  settings. Overlay permission is required; camera detection and experimental
  Photo/Video detection remain optional. Setup resumes where you left off.
- Hands-on SAFE practice: show the mask, then hide it before continuing.
- **Calibrate now** opens an app list so you can choose your camera and adjust
  the visible mask directly over its preview. **Skip** continues setup without
  calibration. The same flow is available under **Customize mask**.
- Height arrows move the mask by **1 dp per tap**, matching the slider. Hold an
  arrow for continuous movement and release to stop. SAFE and the arrows stay
  on the right, with the stronger green **Done** button to their left during
  guided calibration.
- Done saves the position and returns to setup or the control screen. After
  calibration, arrows remain hidden until explicitly enabled in Customize mask;
  manual arrows do not show Done. Existing saved adjustments are preserved.
- Clearer messages for missing overlay permission, camera selection and actual
  accessibility activation, plus help for Android's restricted settings.
- Added the community offset profile for realme RMX5051, Android API 36,
  `com.oplus.camera` 6.020.956, with a vertical offset of 38 dp.
- Updated English, Italian, French, Spanish and German instructions.

Android 8.0 or later is required. Version code: **12**; target API: **36**.
The APK uses the existing distribution signing key. The Google Play build omits
Internet permission and the GitHub update check; Play handles its updates.

Verification: debug, release and Play builds; Android lint with no errors;
real-device checks for wizard permission gates, practice, restart, optional
routes, disclosure and cancellation, calibration over the camera, physical
arrow taps and holds, right-edge placement, Done on the left, saved positions,
manual arrow controls, interruption, dragging and dismissal.

The exact corresponding GPL-3.0-only source is available in this tag and in
[the source tree](https://github.com/MarcorOnline/SocialSafeArea/tree/v1.5.0).
The release includes the signed APK and `SHA256SUMS.txt`.
