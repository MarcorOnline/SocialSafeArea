# Social Safe Area 1.5.1

- Fixed empty side borders on displays with a different aspect ratio from the
  original reference device. The guide now scales uniformly to the physical
  panel width, preserving its 9:16 geometry.
- The guide window extends across system bars and display cutouts, avoiding
  clipping as Android rotates. Floating controls retain their existing bounds.
- Fixed drag-to-trash dismissal with height arrows on displays with a tall
  navigation bar: the drop target follows the finger even when the button's
  position is constrained to keep the controls reachable.
- Added a verified Google Pixel 2 XL profile: Android 11 / API 30, Google Camera
  8.2.204.362396359.12, 1440 × 2880 at 560 dpi, vertical offset −27 dp.
  Existing manual adjustments are preserved; use **Reset** to apply the profile.
- Added optional experimental Photo/Video detection for that exact Google Camera
  profile in portrait with the camera language set to Italian, English, French,
  Spanish or German. Photo hides the guide while keeping SAFE available; Video restores the saved manual ON/OFF
  choice. Unsupported descriptions and configurations retain manual control.
  The feature remains off by default and requires the existing accessibility
  disclosure, consent and Android permission. No camera images are accessed.
- Added an on-device regression check for full-width coverage and full-display
  window bounds through all four rotations. Updated instructions in all five
  supported interface languages.
- Refreshed store home screenshots in Italian and English and prepared the
  existing README-cover camera screenshot for the store listing.

Android 8.0 or later is required. Version code: **13**; target API: **36**.
The signed GitHub APK uses the existing distribution key. The Play variant still
omits Internet permission and GitHub update checks; its submission and review
status are tracked separately in Play Console.

Verification: debug, release and Play builds; lint with no errors; Pixel 2 XL
checks for full-width/full-window coverage through all four rotations; reference
geometry and all eight mask combinations; profile rules in all five camera
languages; physical one-dp taps and holds, drag-to-trash, calibration and wizard
flows; privacy disclosure and update-check regressions. The Google Camera shutter
descriptions were observed on the real Pixel in all five languages. The APK
certificate matches the published 1.5.0 distribution certificate.
The final live service check on the Pixel also passed Video → Photo → Video
with manual ON preserved; the temporary test accessibility grant was removed.

The exact corresponding GPL-3.0-only source is available in this tag and in
[the source tree](https://github.com/MarcorOnline/SocialSafeArea/tree/v1.5.1).
The release includes the signed APK and `SHA256SUMS.txt`.
